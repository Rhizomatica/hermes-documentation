Further troubleshooting (maintainers)

This installation guide focuses on hardware setup and basic functional tests. For a detailed HERMES system architecture and software stack description (radio control via sbitx_controller, modem/TNC integration, uucpd/uuport, and gateway scheduling), see the document “HERMES Software Description” (software_en.pdf) in the HERMES documentation repository.

Useful service-level commands: 

systemctl status sbitx uucpd
journalctl -f -u sbitx
journalctl -f -u uucpd
