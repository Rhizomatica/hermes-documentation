HERMES installation

The HERMES installation procedure will set up the sBitx radio with HERMES system, and perform the station-specific setup.

The installation is done in two steps. The first one with the pendrive inserted in the radio, and the second without the pendrive.

After preparing the USB pendrive and plugging it to the radio, turn on the radio.

When asked if you want to proceed with the installation, answer “y” and press ENTER, as shown in Figure 2.16.

Figure 2.16: HERMES interactive installer starting.

When asked if you want to write HERMES (copy the system), anwser “y” and press ENTER, as shown in Figure 2.17.

Figure 2.17: HERMES installer question to start writing to internal radio memory.

Then the installer will copy the HERMES system (Figure 2.18) to the internal radio SD card, which will take some time, most likely more than one hour.

Figure 2.18: HERMES installer in process of copying data to internal radio memory.

After the copying is done (shown in Figure 2.19), reboot the radio (just press any key) and REMOVE the pendrive from the radio for the second step of the installation. Also make sure the network cable (Internet) is connected to the radio.

Figure 2.19: HERMES installer finished copy of the system to internal radio memory.

After the radio restarts, you will be asked about the station name to use, as shown in Figure 2.20 and 2.21. Choose one of station names below, by typing the full station name in the installed prompt.

  • bakouma.aco-connexion.org
  • bangassouhub.aco-connexion.org
  • briahub.aco-connexion.org
  • goboudou.aco-connexion.org
  • irabanda.aco-connexion.org

The station “bangassouhub.aco-connexion.org” has the gateway station setup. The gateway station should be deployed in a place with Internet connection.

Figure 2.20: HERMES installer station name prompt.
.

Figure 2.21: Station name field filled with “irabanda.aco-connexion.org”.
.

After the setup is finished, you should see the following message “Press any key to REBOOT the radio...”, as shown in Figure 2.22. Press any key. The installation process is finished.

Figure 2.22: Message that marks the end of installation.

The radio will restart, and the HERMES interface will show up, as shown in Figure 2.23.

Figure 2.23: HERMES system screen.
