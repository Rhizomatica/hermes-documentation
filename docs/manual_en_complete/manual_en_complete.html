HERMES HF Telecommunications Manual (Combined)

Rhizomatica


Date: February 20, 2026

Abstract:

This document is intended to be the primary documentation of the HERMES project. It aggregates the main HERMES manuals into a single, standard LaTeX source, so it remains easy to compile as PDF (pdflatex) and to convert to HTML with tools such as latex2html.
